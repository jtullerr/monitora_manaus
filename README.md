O Monitora Manaus é um protótipo funcional de plugin desenvolvido como simulação de proposta e teste de produto aplicado à realidade urbana, elaborado como trabalho final da disciplina de Planejamento e Gestão do Espaço Urbano do Curso de Bacharelado em Geografia do Instituto de Ciências da Sociedade e Desenvolvimento Regional, Universidade Federal Fluminense (UFF Campos dos Goytacazes - RJ).

O projeto tem como objetivo apoiar o georreferenciamento de câmeras de segurança urbana no Centro de Manaus - AM, simulando uma ferramenta prática para gestão pública, estudos urbanos e auditoria cidadã que permite testar em ambiente SIG fluxos reais de consulta espacial e análise de adequação à Lei Geral de Proteção de Dados (LGPD).

Nota sobre o escopo: Trata-se de um teste para validação funcional da proposta, operando sobre uma base vetorial estruturada para reproduzir o comportamento do sistema em uso real. Os pontos exibidos nesta base não correspondem a câmeras de segurança existentes na vida real, servindo exclusivamente como dados simulados para testar o funcionamento e o uso do plugin.
